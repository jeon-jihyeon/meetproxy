# Slack

- Read the message and the whole thread with the Slack MCP thread reader
  - The digits after `p` in a link are the message ts with a dot after the first 10 digits
  - Also check links and images inside the thread
- Requester: the author of the linked message, plus anyone who asked more in the thread
- Post with the meetproxy `post` tool and the request link. It replies in the thread of that message
- Format: Slack mrkdwn, a bold line and bullets instead of headings
